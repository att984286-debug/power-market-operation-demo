# 售电运营数据分析原型

## 客户负荷、合同覆盖与偏差风险监测

这是一个面向电力行业交流和求职展示的 Streamlit 分析原型。它用三类工商业客户的模拟数据，把售电运营中常见的分析链路串起来：

```text
客户负荷变化 → 预测偏差 → 合同覆盖变化 → 偏差风险 → 运营动作
```

它回答的不是“能不能自动交易”，而是：当客户负荷发生变化时，交易运营人员如何快速定位客户、复核覆盖口径、识别偏差风险，并准备下一步沟通和复盘。

> **重要声明**：本项目全部客户、负荷、天气、价格、合同和风险金额均为模拟或情景假设，不代表任何真实企业、安徽省正式交易规则、正式结算结果或交易收益。

## Demo功能

| 页面 | 运营人员可以查看什么 |
| --- | --- |
| 1｜风险总览 | 模拟分析日的客户状态、风险提示和重点事件 |
| 2｜客户画像 | 三类客户的行业特点、年用电量、最大/平均负荷和负荷率 |
| 3｜负荷分析 | 96点实际负荷、预测负荷、日前申报、工作日/周末曲线和异常事件 |
| 4｜覆盖与风险 | MFG01核心案例的预测电量、实际电量、批发采购分摊仓位、覆盖变化和情景风险暴露 |
| 5｜事件复盘 | 预测、申报、事件获知、负荷变化和运营跟进动作的时间线 |
| 6｜数据可信度 | 数据规模、单位、信息可知时间和模拟边界 |

## 建议的首次查看路径

打开应用后，将侧栏的“模拟分析日”设为 **2026-03-17**，客户筛选设为 **MFG01**，依次查看：

1. **1｜风险总览**：看到设备跳停事件和客户风险提示；
2. **2｜客户画像**：了解制造业客户的运行方式；
3. **3｜负荷分析**：比较96点实际、预测和日前申报曲线；
4. **4｜覆盖与风险**：查看事前覆盖约91.4%与事后实际覆盖约173.0%的变化；
5. **5｜事件复盘**：查看事件获知时间和可执行的运营跟进动作。

覆盖率和仓位展示采用**客户级批发采购分摊分析口径**，不代表售电公司组合整体仓位，也不构成安徽正式市场结算。

## 数据范围

- 3类模拟客户：制造业 MFG01、连续工业 CONT01、商业建筑 COMM01；
- 2026全年、15分钟粒度；
- 105,120条客户记录；
- 只读加载 `data/售电交易辅助分析系统——2026全年模拟数据 v1.0.xlsx`；
- 应用不写回、不修改、不重新生成工作簿。

工作簿中的价格、合同、状态日历、日/月汇总和质量检查页，均服务于本Demo的可复核展示。

## 本地运行

需要 Python 3.12（或兼容的 Python 3.x 环境）。在仓库根目录执行：

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

然后用浏览器打开终端显示的本地地址，通常是 `http://localhost:8501`。

## Streamlit Community Cloud部署

推荐使用 [Streamlit Community Cloud](https://share.streamlit.io/) 做第一版公开分享。

1. 将本仓库推送到 GitHub，并确认仓库根目录直接包含 `app.py`、`data/`、`requirements.txt` 和 `README.md`；
2. 登录 Streamlit Community Cloud，连接 GitHub；
3. 选择 `Create app`，填写仓库、分支和入口文件 `app.py`；
4. 在 Advanced settings 中选择 Python 3.12；
5. 点击 Deploy，等待依赖安装和应用启动；
6. 打开生成的 `https://<subdomain>.streamlit.app/` 链接，按上面的首次查看路径复核。

云端依赖由根目录的 `requirements.txt` 安装。本项目不需要数据库、Secrets、API Key、`packages.txt` 或外部接口。
